# SPI Clock Rate (SCK Frequency)

In master mode, the SPI clock (SCK) is generated by dividing the CPU clock. The divider is selected with three bits: **SPR1** and **SPR0** in the `SPCR` register, and **SPI2X** in the `SPSR` register.

## Formula

```
f_SCK = f_CPU / Divider
```

## Divider Selection

| SPI2X | SPR1 | SPR0 | Divider | SCK at 16 MHz |
| :---: | :--: | :--: | :-----: | :-----------: |
| 0 | 0 | 0 | /4   | 4 MHz   |
| 0 | 0 | 1 | /16  | 1 MHz   |
| 0 | 1 | 0 | /64  | 250 kHz |
| 0 | 1 | 1 | /128 | 125 kHz |
| 1 | 0 | 0 | /2   | 8 MHz   |
| 1 | 0 | 1 | /8   | 2 MHz   |
| 1 | 1 | 0 | /32  | 500 kHz |
| 1 | 1 | 1 | /64  | 250 kHz |

> [!NOTE]
> The /64 divider can be reached in two ways (`SPI2X = 0, SPR = 10` or `SPI2X = 1, SPR = 11`). Both give the same frequency.

## Library Default

`spi_Init()` selects the **/16** divider, which gives **1 MHz** at a 16 MHz CPU clock:

```c
/* Prescaler: 16 => 16MHz/16 = 1MHz */
bitSet  (SPCR, SPR0);
bitClear(SPCR, SPR1);
bitClear(SPSR, SPI2X);
```

## Changing the Speed

Edit these three lines in `spi_Init()`.

**Example: 4 MHz (divider /4)**

```c
bitClear(SPCR, SPR0);
bitClear(SPCR, SPR1);
bitClear(SPSR, SPI2X);
```

**Example: 8 MHz (divider /2, fastest)**

```c
bitClear(SPCR, SPR0);
bitClear(SPCR, SPR1);
bitSet  (SPSR, SPI2X);
```

**Example: 250 kHz (divider /64)**

```c
bitClear(SPCR, SPR0);
bitSet  (SPCR, SPR1);
bitClear(SPSR, SPI2X);
```

## Choosing a Speed

> [!IMPORTANT]
> - Never exceed the **maximum SCK frequency** of the slave device. Check its datasheet.
> - The fastest speed (/2) needs short wires and a clean signal. If communication is unreliable, reduce the speed first.
> - If your CPU clock is not 16 MHz, recalculate with the formula. The values in the library comments assume 16 MHz.
> - Some devices need a slower clock during their initialization phase and allow a higher speed afterwards (for example SD cards).
